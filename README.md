# Политики конфиденциальности и поддержка

Статический двуязычный сайт MyPersonalDevelopers для Univer, Peak: Goals & Habits, Plenka и MinePrine.

Страницы: index.html, univer.html, peak.html, plenka.html, mineprine.html, terms.html.

Публичные контакты поддержки находятся на страницах приложений. Сведения об издателе приведены только в terms.html.

Размещение: GitHub Pages, ветка main, корневая папка. Зависимостей и сборки нет; стили локальные. Исходники приложений, служебные контакты Apple, ключи и данные пользователей в репозиторий не включаются.

При изменении обработки данных обновляйте обе языковые версии соответствующей политики.
