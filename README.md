# Юридические сайты приложений

Статический двуязычный сайт политик конфиденциальности, поддержки и сведений об издателе для Univer, Peak: Goals & Habits, Plenka и MinePrine.

Издатель: Gorshkov Daniil Dmitrievich, физлицо, Россия. Публичный контакт: MyPersonalDevelopers@gmail.com.

Хостинг: GitHub Pages, только аккаунт MyPersonalDevelopers и только юридические сайты. Исходники приложений, пароли и реальные данные пользователей сюда не включать. Обычные проекты вести в прежних разрешённых аккаунтах GorshDany и gorshkovdany-cmd. Это ограничение использования аккаунта действует для данного проекта; оно не является разрешением на новые действия вне запроса владельца.

Открытие: index.html. Публикация: репозиторий MyPersonalDevelopers/mypersonaldevelopers.github.io, Pages из main / (root). Зависимостей и сборки нет. Все стили локальные. Для просмотра можно запустить python3 -m http.server в этом каталоге.

Страницы: univer.html, peak.html, plenka.html, mineprine.html. Якоря: #privacy-en, #privacy-ru, #support-en, #support-ru. Общая правовая информация: terms.html. При изменении фактической обработки обновлять обе языковые версии и дату.

Проверка исходников не является доказательством поведения загруженной в Apple сборки или соответствия законам всех стран. Peak содержит существенное замечание об iCloud/HealthKit; до устранения нельзя считать его готовым к выпуску. Сайт публикует действительное описание текущей реализации, а не юридическое разрешение запрещённого поведения.
